# Playbook：refactor（重构）

## 触发条件

用户要求在保持外部行为不变的前提下进行结构整理、简化或模块重组。

## 前置条件

- 能够识别既有行为和不变量。
- 已获得 `LOCAL_EDIT` 授权。

## 顺序步骤

1. 记录必须保持不变的外部不变量和公共接口。
2. 编辑前执行现有基线测试或检查；没有测试时必须明确说明。
3. 通过 `dw-build` 进行最小、渐进的结构性编辑，不改变无关代码或用户 WIP。
4. 重跑完全相同的基线检查及相关回归检查。
5. 执行 `dw-review`，确认没有意外的行为偏移。

## 证据

- 重构前的基线命令结果、差异摘要及最终编辑后重跑命令的结果。

## 失败与停止条件

- 基线测试原本失败或无法执行时停止，单独报告基线问题。
- 修改公共 API、持久化 Schema 或外部契约之前必须暂停并征求批准。
