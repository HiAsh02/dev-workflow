# Playbook：bug-fix（缺陷修复）

## 触发条件

用户报告错误、回归、崩溃、测试失败或运行时意外行为。

## 前置条件

- 已提供故障现象、失败测试、日志或复现提示。
- 必须区分只读诊断（`READ`）和获授权修复（`LOCAL_EDIT`）。

## 顺序步骤

1. 进入 `dw-debug` 检查症状并建立最小确定性复现。
2. 缩小范围；若是回归，条件允许时与最后已知正常提交或差异比较。
3. 提出可证伪的根因假设，在编辑前通过实验或检查确认。
4. 未获得修复授权时，停止并报告根因及建议补丁。
5. 获得授权后实施最小修复（`dw-build`/`dw-debug`），增加回归测试，并对非简单变更执行 `dw-review`。

## 证据

- 复现步骤或命令、修复前的失败信号、根因位置（`file:line`）及修复后通过的回归检查。

## 失败与停止条件

- 当前环境无法复现时，应停止并报告，不得在不说明缺口的情况下发布猜测性补丁。
- 连续两次以上补丁尝试失败后，停止编辑并重新评估根因假设。
