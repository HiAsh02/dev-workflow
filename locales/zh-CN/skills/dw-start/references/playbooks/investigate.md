# Playbook：investigate（调查分析）

## 触发条件

用户要求检查、解释、高层诊断或评估代码库、架构或依赖，且没有要求修改代码。

## 前置条件

- 可以在工作区或已引用的资料中识别调查范围。
- 授权级别仅为 `READ`。

## 顺序步骤

1. 澄清确切问题及范围边界。
2. 执行只读搜索与针对性文件读取，避免完整转储仓库。
3. 区分直接观察的事实（文件路径、行号、命令输出）与推断、未验证缺口。
4. 用可点击的文件及行号引用简洁总结发现。

## 证据

- 实际观察的确切文件路径、符号、行号和只读命令输出。
- 明确确认没有修改文件，也没有进行远程操作。

## 失败与停止条件

- 必需资料缺失或访问受限时停止，报告具体缺口，不得猜测文件内容。
- 不得把调查请求默默升级为代码编辑或提交。
